# 安全性と信頼境界

## 信頼する対象と残余リスク

単一の信頼できるローカル利用者の配置先・venv・運用指定と、事前確認対象の固定ノードを信頼する。manifest・HTTP・履歴・既存JSON・YAML・外部コマンド応答は型・構造を検査する。テナント・認可は適用外である。固定版だけで安全性を保証しない。固定ノード・プラグイン・依存の確認範囲は [検証記録](../../verification/) に分離する。

ComfyUI / Ollama / Harness はループバックのみで起動し、認証不要の API を外部公開しない。CORS 許可や --listen を付けない。MiniMaxH3SaveVideo の ffmpeg_path は任意の実行物を受け取る。公開6項目は標準経路の契約であり comfyui_run の任意投入を遮断しない。ツール承認・無効化の確認範囲は検証記録に分離し、任意投入の残余リスクは本人判断である。第三者の文章・ファイルをそのままエージェントに実行させない。--accept-license は原文を読んだ本人だけが使い、取得をエージェントに実行させない。

## パス・ファイル・非変更

パスは実行時 Path.home / expanduser で解決する。相対POSIXパスの絶対・空要素・dot・dotdot・NUL・バックスラッシュを拒否し、存在する最も近い祖先と残りの要素を保持し、候補の祖先を上へ辿って基準の dev/inode と samestat 比較し包含を検査する。未存在要素は casefold で比較する。モデル配下のリンクは cache 含め拒否し、各書込直前も再検査する。モデルルートの入口リンクは解決先一致で許す。動画リンクは出力ルート内の通常ファイルだけを許す。同時ディレクトリ差替えは単一利用者の運用外である。

ライブラリのリンクを拒否する。不正 JSON・非リスト・不正項目・対象名重複は未登録に代替しない。register の同名競合は5、check D-4は FAIL、verify の入力不正は2。verify は履歴のノード構成・固定入力を登録項目とリポジトリの両方へ照合してから外部コマンドを起動する。

~/.dsh の永続書込はライブラリの親と workflows.json のみで、保護先・許可先とも同じ dev/inode 比較で、大文字小文字・シンボリックリンク・別マウント経路の別名も検査する。~/.dsh/data と ~/.dsh/data/dsh-comfyui のいずれかがシンボリックリンクなら register は書込み前に2で拒否する。workflows.json 自体のリンクも2で拒否する。profile/env の変更は手作業だけであり、シェル設定・他ノードを書き換えない。一時JSONは同じ親で作成・fsync・原本再確認・replace し成功/失敗とも除去する。途中モデル・不一致・既存リンク競合は保持し自動修復しない。

## URL・外部コマンド・配布境界

ローカル API は http/https、IP リテラル127/8または::1、port1〜65535だけを許す。localhost/DNS・userinfo/query/fragment・用途外パスを拒否する。urllib は ProxyHandler({}) と redirect 拒否を使う。応答本文・未加工例外は表示しない。

外部処理は引数リスト・shell=False・期限付き・stdin=DEVNULL である。ffmpeg の全デコードには -nostdin を付ける。実行物は絶対パスでリンク先の通常ファイル・実行権限を検査する。venv Python のリンクは検査後も入口のパスで -I 起動し、venv を保持する。ffmpeg / ffprobe は登録ライブラリ・履歴から実行物パスを導出せず、リポジトリの Save 固定入力だけから導出する。

子環境は HOME / PATH / locale / TMPDIR だけを基本とし、秘密・proxy・任意Git/pip/HF設定を継承しない。pip 全呼出しは --isolated、接続時は明示 https://pypi.org/simple、PIP_CONFIG_FILE=/dev/null。Gitは固定 GitHub repo、子の GIT_CONFIG_GLOBAL=/dev/null・GIT_CONFIG_NOSYSTEM=1・GIT_TERMINAL_PROMPT=0 で利用者の insteadOf を使わない。hook・権限・TLS を無効化しない。pip は導入前 check の不整合を非変更5で拒否し、計画と導入の両方で --only-binary :all: を使いソース配布物をビルドしない。wheel が無く計画できない場合は非変更1である。入れ替え検出は配布名に基づき別名配布物のファイル衝突は検出しない。pip 計画が既存配布物に触れる場合は同版でも導入前に拒否し、導入後も既存版不変と pip check を確認する。自動巻戻しはない。

HF は https://huggingface.co の固定リビジョン・標準 hub 転送、token=False、hub import 前の暗黙トークン無効固定と隔離環境を使う。独自の転送ホスト許可リストを設けない。一覧生成APIにもトークンを付けない。存在・サイズ一致は暗号学的な完全性保証ではない。

## キー・公開資料

D-6 は SafeLoader を基に未知タグを不透明に読む。任意オブジェクトを生成せず、対象設定の重複・曖昧さ・不透明値は UNKNOWN。env は行のキーを先に照合し対象キー以外の値を分割・保持しない。対象の非空存在だけを確認し、全値を非表示・非変更にする。source/eval・展開はしない。設定例には非秘密ダミー値だけを使う。

公開成果物は重み・秘密・個人の絶対パスを含めない。文書のホームは ~、ログは実データ照合後にホームを ~ へ置き換える。HTTP本文・外部処理 stderr の全文・profile 全文をログにしない。標準経路の公開値の表示は生成条件の追跡用である。UDP・CORS 設定は診断対象外である。依存の内容・async・ツール承認機構の確認範囲は検証記録を参照する。悪意のある Web ページからブラウザ経由でループバックの ComfyUI API へ要求を送る経路は CORS 許可付きの起動で成立しやすくなる。
